# Behavior-contract checklist

A documented runtime promise holds only while a test fails when it breaks.
Each row below is one such promise: a one-line claim, the doc section that
owns it, and the tests that pin it. The explanation lives in the linked
section, not here.

Rules for rows:

- **Only documented runtime promises.** A behavior a caller or adapter
  author relies on, stated in the docs or a public doc-comment. Not every
  sentence, and not internal mechanics.
- **Exact test names.** Cite `file.spec.ts` → "the exact test name". CI
  (`pnpm check:contracts`) fails when a cited test does not exist in the
  cited file, so a rename has to update its row.
- **Short.** One line of claim, no history or ticket numbers. When the
  promise needs explaining, explain it in the owning doc.

Store claims are pinned in the TCK (`libs/act-tck/src/store-tck.ts`), so
they run on InMemory, Postgres and SQLite at once.
