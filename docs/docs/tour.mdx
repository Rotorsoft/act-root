# Framework tour

Every capability of Act, from a first action to closing the books, shown as what it does to
the **event store**: one ordered log that every stream shares. The log stays in the middle of
the stage the whole time. Watch it grow, get read, claimed, pruned, truncated and rebuilt.

Pick a chapter, then press **Play** or step with the arrows. Each scene links the page that
explains it and the test that proves it. Chapters are ordered from a first app to production,
operations and adapters; the tag on each says who it's mostly for.
