# The half of the fix that shipped

A commit message is a claim about the world, and the world does not check it. The commit that fixed the presence bug was titled "broadcast a Set as an array on both wire paths." Its body promised that a reconnecting client's reseed would match what a live client holds. The behavior-contract table was updated to say so, and the sentence there names `publish()` before it names `overlay()`. Every one of those statements was written in good faith, and only one of the two paths was actually changed.

The bug being fixed was small and nasty. A `Set` has no useful JSON encoding: `JSON.stringify` turns it into `{}`. The framework's own presence tracker returns a `Set`, and the documented recipe hands it straight to the broadcast layer, so the recommended way to show who is online shipped an empty object to every browser. It then froze, because a client holding `{}` compares each later empty patch against what it has, concludes nothing changed, and stops updating that field for the rest of the session. The repair was a converter that turns a `Set` into an array, applied before the value reaches either the cache or the wire.

Applied before the value reaches the cache in `overlay()`, that is. `publish()` kept writing the caller's state object into the cache untouched, and normalized only the patches on their way out. So the live frame carried `["alice"]` and the reseed carried `{}`, which is the original bug surviving inside its own fix, reachable by nothing more exotic than reconnecting. The half that got fixed was the half the tests exercised, and the tests were written against the function the author was editing.

The tempting repair is one line: run the converter on the cached value too. It is wrong, and the reason it is wrong is the interesting part of this change. That converter does two jobs, not one. It turns Sets into arrays, which the cache wants. It also turns `undefined` into `null`, which the cache specifically must not do, because a separate decision had already settled that a reseed shows a cleared field as absent rather than null, and there is a test pinning it. And because it rebuilds plain objects by walking their entries, it silently drops symbol keys, one of which is the bookkeeping that carries presence across a commit for a third feature. The one-line fix would have quietly broken two deliberate decisions to repair one accident. `overlay()` escapes all of this by luck of ordering: it converts the small patch rather than the whole state, and re-attaches the symbol afterward.

So the shape that shipped is one walker with one parameter. There is a single recursive function that knows how to normalize a value, and the only thing its two callers disagree about is whether a missing value should become `null`. Writing two functions would have been easier to read for a week and wrong within a year, because the moment either side grew a case the other would drift, which is exactly how the original bug came to exist. Symbol preservation stopped being a difference at all once it was looked at properly: symbols are invisible to `JSON.stringify`, so keeping them costs the wire nothing, and the marker stays off the wire for the reason it always did rather than because a rebuild happened to erase it.

The same investigation turned up two siblings that are really the same mistake at a different altitude. The first is that when the cache evicts a stream, any presence data living only in that cache is gone, and `publish()` had no baseline left to carry it from. The path through `overlay()` had been hardened for exactly this and says so at length in a comment; the path through `publish()` had not, and lost the data in silence. The fix is not to make the data survive, because it genuinely cannot. It is to notice. Eviction is the moment the loss happens and the last moment the evicted object can still be inspected, so that is where the report belongs. Doing it there also sidesteps the obvious alternative of keeping a side table of streams that once had overlays, which is precisely the parallel structure the original design rejected when it chose to hang the marker on the cached object.

The second sibling is a queue. Each connection holds a bounded backlog of undelivered frames, and when it fills, the oldest is dropped. The comment justifying that says every frame is a full version-keyed patch, so the consumer converges regardless of what it skips. That is true of ordinary patches and false of the two marker frames the same package emits. A dropped patch announces itself, because the next one skips a version and the client refetches. A dropped overlay announces nothing. Worst of all, the frame that says "you missed something" was itself droppable, so the mechanism built to rescue a client could be discarded on the way to that client.

The rule that replaced it is that you may only drop a frame that can be missed loudly. Evict the oldest version-keyed frame, because its absence is self-announcing. If the entire backlog is version-neutral there is no such frame, and the answer is to collapse the whole backlog into the single frame that means "refetch" — which loses nothing, because a refetch supersedes anything it replaced. That last clause is what makes the collapse safe even when the cap is one and there is no room left for the frame that triggered it.

The thread running through all three is that silence is a design decision, and usually an unexamined one. Data that cannot survive is a fact of life; data that disappears without anybody being told is a bug. Every one of these fixes is the same move: keep the loss, add the signal. And the thread running through how they were found is less comfortable. Three separate places asserted a guarantee the code did not provide, and all three were written by someone who had just made that guarantee true somewhere else. A doc comment, a commit message, and a contract table are not evidence. The test is the evidence, and where the test only covers the half you were editing, the other half is where the bug lives.

## Connections to other chapters

The delete-encoding decision this fix had to preserve is its own essay, and the overlay carry it must not clobber is another; this change is mostly an exercise in not breaking either while fixing a third thing. The eviction reporting belongs beside the essay on bounded collections and the invariants they cannot hold, which reached the same conclusion from the other end: a cache may hold an answer but never own it. And the backlog rule is a small instance of the at-least-once bargain the framework makes everywhere else, where the system's job is not to guarantee delivery but to guarantee that a gap is visible.
